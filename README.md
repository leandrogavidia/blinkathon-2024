# Blinkathon 2024

This repository contains three Solana actions that participated in the Blinkathon, organized by The Send Coin project in 2024.

## Create Squads Multisig (Winner in the Squads Protocol category)

This Solana action allows you to create a Multisig account in Squads Protocol V3.

## KMNO Staking (Winner in the Kamino Finance category)

This Solana action allows you to perform staking and unstaking of the KMNO token in Kamino Finance.

## Pay With Send Token

This Solana action allows you to receive payments in the SEND token using any token.
